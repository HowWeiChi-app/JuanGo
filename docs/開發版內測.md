# 開發版內測：下載連結和開 Pro

開發版（battle 分支，含單字對戰）只給內測同學用，只有 Android 64 位元 ARM（arm64）版。

- **安裝檔：** 放在 Supabase 的私人空間 `dev-builds`，外人拿不到。
- **新同學：** 用「一次性連結」下載。
- **已經在內測名單的帳號：** 打開 App 會自己提醒下載新版。

以下的 SQL 都在 Supabase 儀表板執行：選 HowWeiChi-app-JuanGo 專案 → 左邊 SQL Editor → New query → 貼上 → Run。如果跳出 Potential issue detected，按 Run query。

---

## 一次性下載連結

### 產生一條連結

```sql
select public.dev_link_new('同學名字');
```

`'同學名字'` 換成任何你認得的名字（例如 `'小美'`），它只是備註，用來分辨連結是給誰的，同學看不到。結果是一條 `https://howweichi-app.github.io/JuanGo-dev/?t=…`，傳給同學就好。

- 打開連結是下載頁。按「下載安裝檔」之後連結就失效，下載網址只能用 10 分鐘。
- LINE、IG 的連結預覽不會用掉連結。
- 下載中斷或要給第二個人，就再產生一條。
- 連結下載到的一律是最新的那一版。

### 看哪些連結用過了

```sql
select note, created_at, used_at, used_build from public.dev_links order by created_at desc;
```

`used_at` 是空的，代表還沒用。

### 作廢一條還沒用的連結

```sql
update public.dev_links set used_at = now() where note = '同學名字' and used_at is null;
```

### 改連結或內測名單上的備註名字

之前產生時用的名字（例如 `'同學'`）可以改掉：

```sql
update public.dev_links set note = '新名字' where note = '舊名字';
update public.dev_testers set note = '新名字' where note = '舊名字';
```

## 開 Pro

開發版 App 本身已經把所有付費功能打開。Pro 只影響伺服器算的「對戰每天場次」。

開 Pro 的同時要把她加進內測名單，她才收得到之後的更新。

### 1. 等同學先做好

- 用一次性連結裝好 App。
- 在「我的」頁面登入。
- 用對戰名字找她的話，她要先進過一次單字對戰並取好名字。

### 2. 找到她的帳號 id

用 email 找：

```sql
select id, email, created_at from auth.users where email = '她的email';
```

或用對戰名字找：

```sql
select u.id, u.email, p.name from public.battle_players p
join auth.users u on u.id = p.user_id where p.name = '她的對戰名字';
```

確認只有一列、而且是她，再複製 `id`（一長串 uuid）。

### 3. 開三個月 Pro，並加進內測名單

把 `她的id` 全部換成剛才的 uuid：

```sql
insert into public.entitlements (user_id, entitlement, source, status, expires_at)
values ('她的id', 'juango_pro', 'promo', 'active', now() + interval '3 months')
on conflict (user_id, entitlement) do update
  set status = 'active', expires_at = excluded.expires_at, updated_at = now();

insert into public.dev_testers (user_id, note) values ('她的id', '同學名字')
on conflict do nothing;

select public.has_pro('她的id') as pro;
```

`pro` 顯示 `true` 就成功了。

### 延長

把上面第 3 步的 `interval '3 months'` 改成想要的長度（例如 `'6 months'`），再執行一次。注意是從執行當下重新算起。

### 取消 Pro

```sql
update public.entitlements set status = 'expired', updated_at = now()
where user_id = '她的id' and entitlement = 'juango_pro';
```

### 從內測名單移除

移除後她不會再收到更新提醒：

```sql
delete from public.dev_testers where user_id = '她的id';
```

### 看目前誰有 Pro、誰在內測名單

```sql
select u.email, e.status, e.expires_at from public.entitlements e
join auth.users u on u.id = e.user_id where e.entitlement = 'juango_pro';

select u.email, t.note, t.added_at from public.dev_testers t
join auth.users u on u.id = t.user_id;
```

## 發新的開發版

在 `捲字 JuanGo 開發版` 資料夾執行。

1. 執行下面的指令，編號會自動 +1，然後編譯安裝檔：

   ```bash
   bash tools/release_dev.sh build "這版改了什麼"
   ```

2. 把它最後印出的「第一段 SQL」貼到 SQL Editor 執行。這段只暫時允許上傳這一個檔名。

3. 執行下面的指令上傳安裝檔：

   ```bash
   bash tools/release_dev.sh upload
   ```

4. 把它印出的「第二段 SQL」貼去執行。這段會收回上傳權限，並登記這一版。

完成後：

- 內測名單裡的人，下次打開 App 會跳「有新的開發版」。
- 之後新產生的一次性連結也會下載到這一版。

每一版的編號都要比上一版大，不然 App 不會提醒，也沒辦法覆蓋安裝。

## 哪些手機裝不了

安裝檔只有 64 位元 ARM（arm64）版。

- **可以裝：** 大部分近幾年的手機，例如 Samsung Galaxy A56 和其他 A 系列中高階機。
- **裝不了：**
  - 系統是 32 位元的入門機，例如 Samsung Galaxy A2 Core、A01 Core、A03 Core、J2 Core、M01 Core。
  - Intel Atom 的舊手機和平板，例如 ASUS ZenFone 2、4、5、6。
  - Intel 或 AMD 的 Chromebook。
  - 電腦上的 x86 模擬器。

如果安裝時出現「應用程式未安裝」或「與裝置不相容」，就是這種情況，需要另外編 32 位元 ARM 版。

安裝時三星可能會出現兩種提示，都是正常的：

- 問要不要允許安裝不明來源的應用程式：開啟允許，再按返回繼續。
- 「Play 安全防護」警告：按「更多詳細資料」→「仍要安裝」。
