# 測試版下載連結

## iPhone：SideInstaller／SideStore／LiveContainer

用 GitHub Release 的直接下載網址（安裝時由 SideStore 或 LiveContainer 用自己的 Apple ID 重新簽名）：

```
https://github.com/HowWeiChi-app/JuanGo/releases/download/v0.2.0/JuanGo-0.2.0.ipa
```

一鍵安裝連結（在 iPhone 用 Safari 打開，交給 SideInstaller 安裝）：

```
https://sideinstaller.net/open.html?url=https%3A%2F%2Fgithub.com%2FHowWeiChi-app%2FJuanGo%2Freleases%2Fdownload%2Fv0.2.0%2FJuanGo-0.2.0.ipa
```

發新版時把網址裡的兩個版本號換掉。

## Android：一次性下載連結

安裝檔（arm64）放在 Supabase 私人空間 `dev-builds`，外人拿不到。SQL 在 Supabase 儀表板執行：HowWeiChi-app-JuanGo 專案 → SQL Editor → New query → 貼上 → Run（跳出 Potential issue detected 就按 Run query）。

### 產生一條連結

```sql
select public.dev_link_new('名字');
```

名字只是備註，對方看不到。結果是一條 `https://howweichi-app.github.io/juango/download/?t=…`，傳給對方就好。

- 打開是下載頁，按「下載安裝檔」後連結就失效，下載網址 10 分鐘內有效。
- LINE、IG 的連結預覽不會用掉連結。
- 下載到的一律是最新登記的那一版。

### 看哪些連結用過了

```sql
select note, created_at, used_at, used_build from public.dev_links order by created_at desc;
```

### 作廢一條還沒用的連結

```sql
update public.dev_links set used_at = now() where note = '名字' and used_at is null;
```

### 放上新版

1. `bash tools/build_release.sh`（GitHub Release 用的 APK、IPA）
2. `bash tools/release_link.sh build "這版改了什麼"`，把印出的第一段 SQL 貼去執行
3. `bash tools/release_link.sh upload`，把第二段 SQL 貼去執行

資料表、函式在 `supabase/dev_builds.sql`，下載函式在 `supabase/functions/dev-download/`（從儀表板部署，關閉 JWT 驗證）。下載頁在開發者官網 repo 的 `juango/download/index.html`。
